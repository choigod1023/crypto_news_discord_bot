# Coinness Discord ニュースボット

[한국어](README.md) · **日本語** · [English](README.en.md)

Coinness API を使って暗号資産ニュースをリアルタイムに取得し、Discord へ送信するシンプルなボットです。

## 🚀 機能

- 📰 10 秒ごとに新着ニュースを自動検知
- 🔥 重要ニュースと通常ニュースを区別
- 📊 市場の反応（上昇／下落の投票）を表示
- 🎨 Discord の埋め込み（Embed）形式で見やすいメッセージ
- 💾 ファイル比較方式で重複を防止

## 📋 必要条件

- Python 3.8 以上
- Discord ボットトークン
- インターネット接続

## 🛠️ セットアップ

### 1. 必要なパッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. 環境変数の設定

プロジェクトルートに `.env` ファイルを作成し、次の内容を記述します:

```
DISCORD_BOT_TOKEN=your_discord_bot_token_here
COINNESS_API_URL=https://api.coinness.com/feed/v1/breaking-news
```

> **メモ**
> - `DISCORD_BOT_TOKEN` は **必須** です。無い場合、ボットは起動せず案内メッセージを表示して終了します。
> - `COINNESS_API_URL` はコード内で `os.getenv('COINNESS_API_URL')` として読み込むニュース API のエンドポイントです。
> - `.env` は `.gitignore` に含まれており、Git にコミットされません。

## 🤖 Discord ボットの作成方法

1. [Discord Developer Portal](https://discord.com/developers/applications) にアクセス
2. 「New Application」をクリック
3. ボット名を入力して「Create」をクリック
4. 左メニューの「Bot」をクリック
5. 「Add Bot」をクリック
6. 「Token」セクションで「Copy」をクリックしてトークンをコピー
7. `.env` ファイルにトークンを貼り付け

## 🎯 ニュース通知チャンネルの設定方法

1. ニュース通知を受け取りたいチャンネルを選択
2. チャンネル設定（歯車アイコン）をクリック
3. 「概要」タブのチャンネルトピックに `coin_news` と入力
4. 保存

## 🚀 ボットの起動

```bash
python discord_bot.py
```

正常に起動すると、次のようなメッセージが表示されます:

```
코인니스 뉴스 봇#1234이(가) 로그인했습니다!
Bot ID: 123456789012345678
뉴스 알림 대상: 채널 주제가 "coin_news"인 모든 채널
------
발견된 대상 채널: 2개
  - #crypto-news (서버: My Server)
  - #coin-updates (서버: Trading Guild)
------
```

## 🔄 自動機能

- **自動ニュースチェック**: 10 秒ごとに新着ニュースを確認
- **リアルタイム通知**: 新しいニュースがあれば自動で通知を送信
- **重複防止**: ファイル比較方式で送信済みのニュースを除外
- **重要ニュース**: 重要ニュースは赤色で表示し、@everyone メンション＋ピン留め
- **マルチチャンネル対応**: チャンネルトピックが "coin_news" のすべてのチャンネルへ自動送信

## 📁 ファイル構成

```
crypto_news_bot/
├── discord_bot.py      # メインのボット（10 秒周期のニュースチェック・チャンネル探索・Embed 送信）
├── coinness_api.py     # Coinness API クライアント（aiohttp による非同期呼び出し）
├── requirements.txt    # 必要パッケージ一覧
├── .env               # 環境変数（自分で作成、.gitignore 済み）
├── last_news.json     # 前回ニュースの保存ファイル（重複比較用）
└── README.md          # このファイル
```

## ⚠️ 注意事項

- Discord ボットトークンは絶対に公開しないでください
- `.env` ファイルは `.gitignore` に追加することを推奨します
- ボットにメッセージ送信権限があるか確認してください

## 🐛 トラブルシューティング

### ボットが反応しない場合

1. ボットトークンが正しいか確認
2. ボットがサーバーに招待されているか確認
3. ボットにメッセージの読み取り／送信権限があるか確認
4. チャンネルトピックが "coin_news" に設定されているか確認

### API エラーが発生する場合

1. インターネット接続の状態を確認
2. Coinness API サーバーの状態を確認
3. しばらく待ってから再試行

## 📊 API 情報

- **データ提供元**: [Coinness](https://coinness.com)
- **API エンドポイント**: `https://api.coinness.com/feed/v1/breaking-news`
- **言語**: 韓国語 (ko)
- **更新周期**: 10 秒ごとにチェック
